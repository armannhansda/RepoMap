## Reporting a Vulnerability

Please report (suspected) security vulnerabilities to the maintainer via email or private messaging. You will receive a response from us within 48 hours. If the issue is confirmed, we will release a patch as soon as possible depending on complexity.

Please do not open a public issue for security vulnerabilities.
